# Associative indexing

The idea, proposed by [[wiki/entities/Vannevar Bush]], that records should be findable by association — one item leading to the next — rather than by tracing a single path down a fixed alphabetic or numeric classification ([[raw/bush-as-we-may-think.pdf#page=14]]).

## What the sources say
- Conventional indexing files an item in exactly one place, absent duplication; the human mind instead operates by association, snapping from one item to the next along an "intricate web of trails" ([[raw/bush-as-we-may-think.pdf#page=14]]).
- Bush's proposed mechanism on the [[wiki/concepts/Memex]]: the user selects two items on adjacent viewing positions, taps a key, and the items become "permanently joined" — from then on, viewing one lets the user instantly recall the other with a single button press ([[raw/bush-as-we-may-think.pdf#page=16]]).
- Chaining many such joins together forms a "trail" that can be stepped through like a book, branched into side trails, annotated with the user's own comments, and later reproduced and handed to someone else to splice into their own trail set ([[raw/bush-as-we-may-think.pdf]]).
- Bush conceded this could not equal the mind's raw speed and flexibility, but argued it would beat the mind on permanence and clarity — trails don't fade the way memory does ([[raw/bush-as-we-may-think.pdf#page=14]]).
