# BM25

Best Matching 25: a ranking function that finds documents by lexical matching of exact words and phrases ([[raw/anthropic-contextual-retrieval.md]]).

## What the sources say
- Builds on TF-IDF, which measures how important a word is to a document in a collection; BM25 adds document-length normalisation and a saturation function on term frequency so common words don't dominate ([[raw/anthropic-contextual-retrieval.md]]).
- Complements embeddings: embeddings capture meaning but can miss exact matches. For a query like "Error code TS-999", embeddings may return error-code content in general, while BM25 finds the exact string ([[raw/anthropic-contextual-retrieval.md]]).
- Especially effective for queries with unique identifiers or technical terms ([[raw/anthropic-contextual-retrieval.md]]).
- Adding contextual BM25 to contextual embeddings took the retrieval failure rate from 3.7% to 2.9% (baseline 5.7%), under the test conditions on [[wiki/concepts/Contextual Retrieval]]: four domains, Gemini Text 004, top 20 chunks, 1 − recall@20 ([[raw/anthropic-contextual-retrieval.md]]).
- Karpathy recommends qmd for searching a wiki that has outgrown its index: "hybrid BM25/vector search and LLM re-ranking, all on-device" ([[raw/karpathy-llm-wiki.md]]).
